# Ai-Agent-Zyra — ZYRA Marketing Intelligence Agent

نسخة كاملة محدّثة من سستم وكيل زيرا للتسويق (Muse Space) كما هي بتاريخ 2026-11-20:
كود التطبيق، قاعدة البيانات، السكيلز، التعليمات، وملفات الشغل والأبحاث وكل التعلّمات.

## المحتويات
- `space/` — سورس كود تطبيق الـ Space (client + server + drizzle migrations حتى 0015: طبقة الوكالة وكرييتورز وفيديو + سجلات التدقيق النصية).
- `data/app-db.sql` — تفريغ كامل لقاعدة البيانات الحية (SQLite dump) بكل جداولها الـ45: المنافسون، الملاحظات، التنبيهات، تعليمات المالك، التعلّمات، بنود العمل، الأورجانيك وكابشناته، المالية، وكل بيانات السستم.
  - للاسترجاع: `sqlite3 app.db < data/app-db.sql`
- `skills/` — السكيلز الستة: zyra-andromeda-ad-system، master-growth-os، aeo، ai-media-launch-and-audit، creative-strategy-master-system، winning-creatives-framework.
- `connectors/` — كونكتور Meta Marketing API (مستندات + helper) — من غير أي أسرار أو توكنات.
- `agent/` — ملفات تعليمات وذاكرة الوكيل (AGENTS, MEMORY, USER) + سجلات الذاكرة اليومية والأشخاص والمجموعات.
- `instructions/` + `goal/` — تعريفات وظائف التشغيل الآلي (crons) وملف الهدف وملفاته.
- `workfiles/` — أبحاث المنافسين وملفات الكرييتف والإنتلجنس والأورجانيك النصية، وتشمل تحديثات 2026-11-20:
  مكتبة صيغ الإعلانات (بما فيها ملحق الوظائف الخمس §9 ومرجع Cost Per Use المحلي)، مكتبة هوكات زيرا (102 هوك)،
  بنك اتجاهات التصميم بمرجعيات العرض R1–R4، دروس فريزر كوترل، وقالب البرومبت البصري بنسخة زيرا.
- `exports/` — مخرجات HTML: المنهج المتكامل لزيرا (النسخة المعمّقة: 12 وحدة + مشروع تخرج)، كورس دروس الفيديوهين، وخطة مختبر الأبسيل والكروس سيل.
- `inputs/` — ملفات الإدخال الأصلية من المالك (مواصفات ZYRA OS v3.3 والماستر برومبت والكورس).

## غير مُضمَّن في هذا الرفع (قيود أداة الرفع: نصوص فقط، حتى 16MB)
- الملفات الثنائية: صور التصاميم المنتَجة (11 تصميم V2/V3/V4 + أصولها)، لقطات تدقيق البناء (PNG)، ملفات الخطوط (Cairo TTF)، شعار زيرا PNG، وأيقونة الـ Space.
- ملف `app.db` الثنائي نفسه — بياناته كاملة هنا بصيغة SQL في `data/app-db.sql`.
- مخرجات البناء (`dist`) و`node_modules` و`__pycache__` — تُبنى من السورس.
- لرفع الصور والملفات الثنائية أيضاً يلزم رفع Git مباشر (SSH) — اسأل Muse عن «استكمال الرفع بمفتاح SSH».
