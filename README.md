# Ai-Agent-Zyra — ZYRA Marketing Intelligence Agent

نسخة كاملة من سستم وكيل زيرا للتسويق (Muse Space) كما هي بتاريخ 2026-11-19:
كود التطبيق، قاعدة البيانات، السكيلز، التعليمات، وملفات الشغل والأبحاث.

## المحتويات
- `space/` — سورس كود تطبيق الـ Space (client + server + drizzle migrations + سجلات التدقيق النصية).
- `data/app-db.sql` — تفريغ كامل لقاعدة البيانات الحية (SQLite dump) بكل جداولها الـ39: المنافسون، الملاحظات، التنبيهات، تعليمات المالك، التعلّمات، بنود العمل، الأورجانيك وكابشناته، المالية، وكل بيانات السستم.
  - للاسترجاع: `sqlite3 app.db < data/app-db.sql`
- `skills/` — السكيلز الستة: zyra-andromeda-ad-system، master-growth-os، aeo، ai-media-launch-and-audit، creative-strategy-master-system، winning-creatives-framework.
- `connectors/` — كونكتور Meta Marketing API (مستندات + helper) — من غير أي أسرار أو توكنات.
- `agent/` — ملفات تعليمات وذاكرة الوكيل (AGENTS, MEMORY, USER) + سجلات الذاكرة اليومية.
- `instructions/` + `goal/` — تعريفات وظائف التشغيل الآلي (crons) وملف الهدف وملفاته.
- `workfiles/` — أبحاث المنافسين وملفات الكرييتف والأورجانيك النصية.
- `inputs/` — ملفات الإدخال الأصلية من المالك (مواصفات ZYRA OS v3.3 والماستر برومبت والكورس).

## غير مُضمَّن في هذا الرفع (قيود أداة الرفع: نصوص فقط، حتى 16MB)
- الملفات الثنائية: صور التصاميم المنتَجة (11 تصميم V2/V3/V4 + أصولها)، لقطات تدقيق البناء (181 PNG)، ملفات الخطوط (Cairo TTF)، شعار زيرا PNG، وأيقونة الـ Space.
- ملف `app.db` الثنائي نفسه — بياناته كاملة هنا بصيغة SQL في `data/app-db.sql`.
- مخرجات البناء (`dist`) و`node_modules` — تُبنى من السورس.
- لرفع الصور والملفات الثنائية أيضاً يلزم رفع Git مباشر (SSH) — اسأل Muse عن «استكمال الرفع بمفتاح SSH».
