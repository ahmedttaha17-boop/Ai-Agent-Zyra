# Ai-Agent-Zyra — ZYRA Marketing Intelligence Agent

نسخة كاملة محدّثة من سستم وكيل زيرا للتسويق (Muse Space) كما هي بتاريخ 2026-11-21:
كود التطبيق، قاعدة البيانات، السكيلز، التعليمات، وملفات الشغل والأبحاث وكل التعلّمات.
آخر تحديث: الباك اب اليومي 2026-11-21 ~04:52 EET (تفريغ قاعدة بيانات جديد + معيار ذوق المالك وبريفات إعادة إنتاج الـ11 + دفعة KP-10 + كابشنات أول 15 بوست + مخطط سلّم التكلفة).

## المحتويات
- `space/` — سورس كود تطبيق الـ Space (client + server + drizzle migrations حتى 0015: طبقة الوكالة وكرييتورز وفيديو + سجلات التدقيق النصية).
- `data/app-db.sql` — تفريغ كامل لقاعدة البيانات الحية (SQLite dump) بكل جداولها الـ45: المنافسون، الملاحظات، التنبيهات، تعليمات المالك، التعلّمات، بنود العمل، الأورجانيك وكابشناته، المالية، وكل بيانات السستم.
  - للاسترجاع: `sqlite3 app.db < data/app-db.sql`
- `skills/` — السكيلز الستة: zyra-andromeda-ad-system، master-growth-os، aeo، ai-media-launch-and-audit، creative-strategy-master-system، winning-creatives-framework.
- `connectors/` — كونكتور Meta Marketing API (مستندات + helper) — من غير أي أسرار أو توكنات.
- `agent/` — ملفات تعليمات وذاكرة الوكيل (AGENTS, MEMORY, USER) + سجلات الذاكرة اليومية والأشخاص والمجموعات.
- `instructions/` + `goal/` — تعريفات وظائف التشغيل الآلي (crons) وملف الهدف وملفاته.
- `workfiles/` — أبحاث المنافسين وملفات الكرييتف والإنتلجنس والأورجانيك النصية، وتشمل تحديثات 2026-11-20:
  مكتبة صيغ الإعلانات (بما فيها ملحق الوظائف الخمس §9 ومرجع Cost Per Use المحلي)، مكتبة هوكات زيرا (102 هوك)،
  بنك اتجاهات التصميم بمرجعيات العرض R1–R4، دروس فريزر كوترل، وقالب البرومبت البصري بنسخة زيرا.
  جديد في باك اب 2026-11-20 اليومي: بريفات Text on Skin + Google Search + Receipt (KP أولاً)،
  دراسة بوست عروض الجمعة، وحكم قائمة تحقق SEO.
  جديد في باك اب 2026-11-21 اليومي: معيار ذوق المالك (الأصلية 11) وبريفات إعادة إنتاجها
  والـ12 التنفيذية، دفعة KP-10 Andromeda، كابشنات أول 15 بوست (60 خيارًا + اختيارات المالك)،
  مخطط سلّم التكلفة (Bid Cap Ladder)، وجرد شرائح KP الـ12.
- `exports/` — مخرجات HTML: المنهج المتكامل لزيرا (النسخة المعمّقة: 72 درسًا بشرح مدرّب + مشروع تخرج،
  أُعيد تصديرها في هذا الباك اب بعد إعادة بناء الكورس)، كورس دروس الفيديوهين، وخطة مختبر الأبسيل والكروس سيل.
  ملف `exports/lmnhj-lmtkml-pdf.txt` وصف نصي لنسخة PDF من المنهج (116 صفحة، 2026-11-20) — الـ PDF نفسه مضمّن في `binaries/curriculum-pdf/`.
- `inputs/` — ملفات الإدخال الأصلية من المالك (مواصفات ZYRA OS v3.3 والماستر برومبت والكورس).

## الملفات الثنائية — مُضمَّنة الآن عبر Git مباشر (SSH) منذ 2026-11-20
- مجلد `binaries/`: ‏`design-review/` (مجلدات مراجعة التصاميم v1/v2/v3)، `space-audits/` (لقطات تدقيق بناء الـ Space)، `db/app.db` (قاعدة بيانات الـ Space الثنائية نفسها — وبياناتها أيضاً بصيغة SQL في `data/app-db.sql`)، `logo/logo_2.png` (شعار زيرا)، `curriculum-pdf/` (نسخة PDF الكاملة من المنهج المتكامل، 116 صفحة).

- ما زال غير مُضمَّن: مخرجات البناء (`dist`) و`node_modules` و`__pycache__` — تُبنى من السورس.

## ملاحظة عن الحذف
منذ الرفع المباشر عبر Git (2026-11-20) الحذف يتزامن مع الريبو (`git add -A`)، فالملفات
المحذوفة من المصادر الحية تُشال من الريبو أيضًا. آخر تنظيف: باك اب 2026-11-21 شال النسخ القديمة
المتبقية من سكربتات `workfiles/.../creative/produced-v2/` (8 ملفات)،
`workfiles/.../organic/captions-draft-blocks.txt`،
و`goal/crons/weekly/zyra-weekly-model-review__weekly@Fri-10:11:00.md`
(الكرون نفسه ما زال موجودًا باسم `zyra-weekly-model-review__weekly@Tue,Fri-10:11:00.md`).
