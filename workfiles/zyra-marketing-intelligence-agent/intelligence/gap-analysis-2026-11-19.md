# تحليل الفجوات — 2026-11-19 (بعد اكتمال نموذج الوكالة)
## أ) ناقص البيزنس/الإطلاق (مدخلات وقرارات)
1. ميزانية تيست لكل روتين — موقّفة هيكل الإطلاق العددي كله.
2. Bosta API → رسوم ونسب تسليم فعلية (كل البوابات [EST] لحد دلوقتي).
3. اعتماد إرسال بريفات المصمم + بدء إنتاج المصمم.
4. اعتماد التواصل مع الكرييتورز + حسم الـ 7 الموسومين بخلفية خبير.
5. كابشنز الأورجانيك: 0/15 معتمد + إصلاح 4 أخطاء تصاميم (C5/7 سكراب غلط، C2/9 عنوان مشوّه، C5/9 مفقودة، C3/8 وعد شحن مخالف للسياسة).
6. جلسة تصوير الباكشوتس (قائمة اللقطات جاهزة).
7. قرار سعر KP الشطوب: 1,020 موقع × 1,050 مجموع مكوّنات.
8. قرار تفكير 18 + تصفية صندوق القرارات (48 بند).
9. أول دفعة صوت عميل (القسم بصفر مدخلات).
10. COGS باقي الكتالوج (21 منتج) — لأي توسّع بعد الهيروين.
11. تحقق بيكسل/CAPI وتتبّع Purchase على Shopify قبل الإطلاق (غير متحقق بسبب حجب Meta).
12. TikTok: عصر مكتبة الإعلانات لم يتم + قرار دخوله خطة الإطلاق مفتوح.

## ب) ناقص السستم نفسه (تطوير)
1. بيانات أداء حقيقية = صفر (0 حملات/0 أداء/لقطة مالية حقيقية واحدة) — الهيكل اكتمل؛ الناقص هو التشغيل على بيانات الإطلاق نفسه.
2. Meta feed: مسار التصدير اليدوي المؤقت غير مفعّل كبروتوكول (الريتراي الآلي وحده شغال).
3. TikTok كمصدر بيانات غير مربوط إطلاقاً (Ads Library + لغة بحث).
4. تحليل فيديو (هوك أول 3 ثوانٍ + نص منطوق) — التحليل الحالي صور فقط، والفائز في السوق فيديو.
5. صوت العميل: القناة والكرون موجودان، المدخلات صفر.
6. جدولة/نشر الأورجانيك بعد الاعتماد غير مربوطة (النشر يدوي خارج السستم — بقرار حوكمة المالك).
7. نسب تأكيد WhatsApp/COD لا تتغذى تلقائياً (مصدرها Bosta/يدوي).
8. لا تنبيه فوري للأحداث الكبيرة — التنبيهات بإيقاع دوري فقط.
9. مختبر العروض يسجل تجارب؛ تنفيذ قياس A/B الفعلي خارج السستم (Shopify/يدوي).
10. سجل المعايرة: صفر توقعات مُقيّمة فعلياً (لا أداء بعد).
