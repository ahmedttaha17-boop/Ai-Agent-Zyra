# AI Media Launch & Audit

Source methodology: the owner's AI ad-launch and auditing course, adapted to the Master Growth OS. Where this skill conflicts with the brand's own frameworks (for Zyra Care: zyra-andromeda-ad-system), the brand frameworks win.

## Mode 0 — Offline-to-Online (no ad history)

For brands selling offline with no ad account history:

1. Compute the TRUE Break-Even ROAS from unit economics before any spend (never use dashboard ROAS alone — a brand can show 6x ROAS against a 3.5x break-even and still be losing money on growth).
2. Collect offline buyer insights: who buys, why, objections heard in-store/on WhatsApp, repeat behavior.
3. Set industry-benchmark expectations as HYPOTHESIS tags until real data replaces them.
4. First 14 days = 100% exploration budget; no scaling rules apply yet.

## Mode A — 8-Pillar Business & Account Audit

Run before prescribing new creatives or spend. Each pillar gets a status, evidence, and a score; output is one Scorecard (0-100%) with fixes ranked by fastest measurable revenue impact.

1. **Owner Brief + Offline-to-Online status** — goals, constraints, true Break-Even ROAS.
2. **Performance Audit** — Best Period vs Drop Period comparison under fair conditions: store numbers and Ads Manager in ONE sheet (ROAS, CPO, AOV, CR, CTR, CPM, Frequency), matched non-seasonal windows only.
3. **Ad Account Audit + Andromeda Segmentation** — structure hygiene; audience segmentation into 3-7 segments (180d Engaged, 90-730d Existing Customers, broad cold).
4. **Product & Inventory Matrix** — Best / Mid / Worst classification, Units per Order comparison best-vs-worst period, hidden organic winners, 4-5 Hero SKUs, dead stock to clear or kill.
5. **7-Page CRO Audit + Funnel Calculator** — home, collection, product, cart, checkout, offer/landing, confirmation pages; clarity first; GA4 bounce > 60-70% on a paid-traffic page is a red flag.
6. **Social Audit** — content parity with ads (same promises, same proof), profile funnel to purchase.
7. **Operations & Packaging Audit** — confirmation speed, CS quality, packaging/unboxing as a retention asset.
8. **Retention & LTV** — repeat rate, LTV by cohort, WhatsApp/CRM follow-up; feeds the audit Score.

## Mode B — 6-Stage AI Ad Launch

1. **Competitor research** — Meta Ad Library (sort by impressions/longest-running) + TikTok Creative Center: extract offers, angles, formats, longevity.
2. **Prompt engineering & static production** — written prompts locked to brand identity before any image generation.
3. **Landing page build/gap audit** — 7 blocks: Problem, Solution, Cost Math Table, Specs, Risk Reversal, DM-sourced FAQ, What's in the Box + CTA; 100% ad-to-page promise parity.
4. **AI video & UGC/FGC production** — scripts first; on trust-sensitive brands, real creators only (see master-growth-os Precedence Rule 2).
5. **Ad copy** — 3-5 human-sounding Egyptian Arabic copies per angle (Primary Text, Headline, Description).
6. **Structured testing** — 2x CPP rule: any single ad spending >= 2x Target CPP with 0 purchases is an early kill; ABO Flex testing for new SKUs (500 EGP/day, 1 Flexible Ad, up to 10 statics, 1 product URL), winners extracted via Ads Manager into Page Posts/Ad Posts; respect the 48-hour warm window before declaring winners unless the hard kill stop triggers.

## Pre-Flight Gate (all 5 must pass before launch)

Active payment method · Verified Pixel/CAPI · Explicit user budget · Target page live and matching the ad promise · Human QA on copy and visuals.
