# Master Growth OS (Unified Multi-Skill Flow)

An automatic orchestration layer that unifies all active marketing and execution skills into one sequential, closed-loop 7-stage workflow with explicit conflict-resolution rules and deterministic verification.

## When to Use

- Any end-to-end e-commerce launch, scaling plan, or weekly/monthly growth review
- Any business, store, CRO, operations, or Meta Ads account audit
- Any creative strategy, angle/hook matrix, UGC/FGC script, static brief, or pricing/bundle engineering task
- Any Zyra Care marketing, creative, financial, or Meta Andromeda 2.0 campaign task
- Any multi-step execution task requiring verified evidence before declaring completion

## Automatic Skill Orchestration Map

Load only the minimal sub-skills needed for the active stage rather than dumping unused theory:

- **Execution Spine (aeo):** Governs every task with Understand -> Explore -> Decide -> Split -> Test -> Fix, Evidence Ledger, and verification gates.
- **Audit and Launch Ops (ai-media-launch-and-audit):** Supplies Mode 0 (Offline-to-Online), Mode A (8-Pillar Business and Performance Audit + 7-Page CRO + Scorecard), and Mode B (6-Stage AI Ad Library Research, Landing Page Gap Audit, Pre-Flight Gate, 2x CPP and ABO Flex Testing).
- **Creative and Offer Brain (creative-strategy-master-system + winning-creatives-framework):** Supplies 5 Whys / 7Ws ICP profiling, Rule of One, True Creative Diversity vs Variations (anti-Similarity Penalty), VCC Pillars, Written Creative Briefs, Pricing Psychology (Bundles, Decoy Pricing, +15-20% Free Shipping Threshold, Pre-Payment InstaPay Incentive), and Vertical/Horizontal Scaling.
- **Brand Governance and Deterministic Validators (zyra-andromeda-ad-system):** Activates automatically on any Zyra Care task, enforcing the 8-stage ZYRA THINK -> ACT -> CRITIQUE -> VALIDATE loop, zero double-counting COD math (scripts/cod_cohort_calc.py), compliance validation (scripts/validate_zyra_output.py), brand palette (#013835, #FFF2E9, #E2915A), and Evidence Hierarchy tags.

## Cross-Skill Precedence Rules (Zero Contradictions)

When two skills offer different defaults, apply these exact best-practice resolutions:

1. **Brand Override:** For any Zyra Care task, zyra-andromeda-ad-system compliance, brand palette, SKU naming (use Product Names until live Shopify SKU verification), and COD math rules override generic defaults.
2. **AI UGC vs Authentic Creators:** Strictly forbid AI-generated human faces and fake AI UGC on Zyra Care and trust-sensitive brands (use real UGC, FGC, and expert/pharmacist authority). Allow AI video tools only for non-Zyra rapid concept tests, product B-roll, or clean voiceover with mandatory Human QA.
3. **Testing Structure Routing:**
   - New SKU or low-liquidity rapid signal -> ABO 500 EGP/day + 1 Flexible Ad (10 statics, 1 product URL) and extract winners via Ads Manager -> Page Posts / Ad Posts.
   - Proven SKU creative testing -> 1 Ad Set = 3 Ads @ 2x Target CPP/day (3-day window; Early Kill any single ad spending >= 2x CPP with 0 purchases) OR 3:2:2 (3 Visuals x 2 Primary Texts x 2 Headlines = 12 combinations) for Andromeda retrieval diversity.
   - Respect the 48-hour initial warm-audience window before declaring winners, unless an ad hits the hard 2x CPP zero-purchase kill stop.
4. **Financial Truth:** Never double-count Placed CPP, Delivered CPP, and RTO. Compute Break-Even ROAS, Placed CPP, Delivered CPP, and Cohort Contribution strictly on the same cohort and timeframe. Never invent missing COGS, budgets, or benchmarks.
5. **Human Control Gate:** Never publish live ads, alter budgets/prices/discounts, pause live campaigns, or message customers without explicit user confirmation.

## The Unified 7-Stage Automatic Flow

Execute all relevant stages in order; for narrow requests, enter at the matching stage while still respecting Stage 1 (Grounding) and Stage 6 (Critique and Validate).

### Stage 1: Understand, Scope, and Ground (aeo + zyra-andromeda-ad-system)

- Define the commercial objective, target brand (Zyra Care vs general brand), and measurable success criteria.
- Check existing user data, workspace files, and verified unit economics first. Tag every input as VERIFIED, ZYRA PROVEN, HYPOTHESIS, ESTIMATED, or UNKNOWN.
- If launching an offline-to-online brand with no ad history, activate ai-media-launch-and-audit Mode 0 (true Break-Even ROAS + industry benchmarks + offline buyer insights).

### Stage 2: Full-Funnel Business and Account Diagnosis (ai-media-launch-and-audit Mode A)

Run the 8-Pillar Audit before prescribing new creatives or spend: Owner Brief and Break-Even ROAS -> Matched Non-Seasonal Macro Performance (ROAS, CPO, AOV, CR, CTR, CPM, Frequency) -> Pixel/CAPI and Andromeda Audience Segmentation (180d Engaged, 90-730d Existing) -> Product/Inventory Matrix (Hidden Organic Winners, 4-5 Hero SKUs, Dead Stock) -> 7-Page CRO Funnel Diagnostics (Clarity + GA4 Bounce Rate > 60-70%) -> Social/Message Parity -> Operations/Confirmation/CS/Packaging -> Retention and LTV.

Output an 8-Pillar Scorecard (0-100%) and rank fixes by fastest measurable revenue impact first.

### Stage 3: ICP Psychology, Offer Engineering, and Creative Architecture (creative-strategy-master-system + winning-creatives-framework)

- Map the 5 Customer Needs, 5 Whys Hidden Need, and 7Ws ICP segments (enforce the 3-to-7 Micro-Segments Scaling Rule).
- Engineer the offer to protect Contribution Margin and lift AOV/delivery rate: Routine Bundles, Decoy Pricing, +15-20% Free Shipping Threshold, Risk Reversal, and 5-10% Pre-Payment InstaPay/Card incentive.
- Build a True Creative Diversity Matrix across VCC Pillars (Visibility, Credibility, Conversion) and 6 Master Angles using the Rule of One (1 Emotional Need + 1 Resolved Objection + 1 Social Proof per ad) to prevent Andromeda Similarity Penalty.

### Stage 4: Production Assets and High-CR Landing Page (ai-media-launch-and-audit Mode B + creative-strategy-master-system)

- Run Meta Ad Library research (highest-impression, longest-running ads) to extract top 5 competitor offers, angles, and supplier-copy gaps.
- Produce written Creative Briefs (never vague notes), parallel Static prompts (7 Store Gallery + 8+ Paid Ad prompts locked to Brand Identity), authentic UGC/FGC scripts, and 3-5 human-sounding Egyptian Arabic Ad Copies (Primary Text, Headline, Description).
- Build or Gap-Audit the 7-block High-CR Landing Page (Problem, Solution, Cost Math Table, Specs, Risk Reversal, DM-sourced FAQ, What is in the Box + CTA) and enforce 100% ad-to-page promise parity.

### Stage 5: Pre-Flight Launch and Structured Testing (ai-media-launch-and-audit Mode B)

- Pass all 5 Pre-Flight Checks: Active Payment Method, Verified Pixel/CAPI, Explicit User Budget, Target Page, and Human QA on copy/visuals.
- Launch using the routed Testing Structure from Precedence Rule 3, ensuring 1 product URL per Flexible Ad Set and operational fulfillment readiness before scaling.

### Stage 6: Independent Critique and Deterministic Validation (aeo + zyra-andromeda-ad-system)

- Run an independent Critic pass checking for Similarity Penalty, ad-to-page mismatch, robotic AI phrasing, double-counting, unverified claims, and seasonal comparison errors.
- For Zyra Care outputs, deterministically run scripts/validate_zyra_output.py on copy/ads and scripts/cod_cohort_calc.py on financial/COD calculations.
- For software, HTML, or data deliverables, run real verification checks and inspect outputs before handoff. Fix every blocker and re-verify.

### Stage 7: Closed-Loop Audit, Dual Scaling, and Learning (All Skills)

- Audit 7-to-30-day performance against brand benchmarks and assign verdicts: KEEP, ITERATE, KILL, SCALE, INVESTIGATE, or INSUFFICIENT DATA.
- Kill underperformers (Low CTR + High CPM + 0 Purchases or >= 2x CPP with 0 purchases).
- Scale confirmed winners via Vertical Scaling (generate 5+ new prompts/hooks/creators/formats modeled on the winning angle) and Horizontal Scaling (launch new ICP micro-segments and Human Needs monthly).
- Log each experiment (Hypothesis, Angle/Hook, Budget, Actuals, Verdict) to update the Proven Wrapper Library and Dead Angle Graveyard.

## Gotchas

- Never dump every framework on a small task; route only the stages and sub-skills needed for the user's immediate goal.
- Never skip Stage 6 verification; unvalidated copy, unverified COD math, or untested files are not done.
- Never scale ad spend before verifying inventory depth, confirmation speed, and fulfillment capacity.
